# 🚀 Featured Projects

## ☁️ VProfile — Multi-Cloud DevOps Automation

**DevOps • AWS • GCP • Kubernetes • Terraform • Jenkins • ArgoCD**

A multi-tier Java application deployed across AWS and GCP with automated infrastructure provisioning and CI/CD.

- Provisioned Nginx, Tomcat, RabbitMQ, Memcache, and MySQL using Vagrant.
- Migrated and re-architected workloads using AWS EC2, ELB, Auto Scaling, RDS, Route53, Elastic Beanstalk, ElastiCache, and AmazonMQ.
- Built CI/CD pipelines with Jenkins, SonarQube, Nexus, AWS CodePipeline, and CodeBuild.
- Containerized the application with Docker and Kubernetes using Helm, autoscaling, Ingress, and ArgoCD GitOps workflows.

---

## 🌍 Safar — Production Travel Discovery Platform

**React • TypeScript • Node.js • Express • MongoDB • AWS • Docker**

A full-stack travel-sharing platform focused on discovering camps and travel destinations.

- Built with React 19, TypeScript, Vite, Zustand, Tailwind CSS, Node.js, Express, and MongoDB.
- Added Mapbox maps, Cloudinary uploads, reviews, favorites, and role-based admin functionality.
- Implemented JWT authentication, HttpOnly cookies, refresh-token rotation, email verification, rate limiting, and security protections.
- Containerized and deployed using Docker, Nginx, AWS EC2, and automated deployment scripts.
- Added Prometheus, Grafana, Loki, GitHub Actions, and Trivy for observability, CI/CD, and security scanning.

## 📈 Student Performance Prediction

**Machine Learning • EDA • Regression • Scikit-learn • Flask • AWS**

- Performed EDA across demographic, socioeconomic, and academic features.
- Evaluated **9 regression models** using GridSearchCV and 3-Fold Cross-Validation.
- Achieved a best test **R² score of 0.8806**.
- Built an end-to-end pipeline covering preprocessing, serialization, inference, and AWS Elastic Beanstalk deployment.

## 🧠 AQI Analysis & Prediction

**Machine Learning • ANN • Data Analysis**

Research project focused on AQI behavior across Indian cities.

- Analyzed AQI trends for **7 Indian cities over 60 days**.
- Built ML models using lag characteristics on **14,000+ samples**.
- Achieved an RMSE of **26** with initial ML models.
- Developed an ANN-based model that improved performance to an RMSE of **22**.

## 🚘 Automatic Number Plate Recognition

**Computer Vision • YOLOv8 • OCR • OpenCV • SORT**

- Built a real-time ANPR pipeline using dual YOLOv8 models.
- Detected vehicles across **4 vehicle classes** and identified license plates.
- Integrated SORT with Kalman filtering and Hungarian IoU matching.
- Used OpenCV preprocessing, EasyOCR, and SciPy interpolation to generate structured records.

## ✍️ Next Word Prediction using LSTM

**Deep Learning • NLP • TensorFlow • Keras • Streamlit**

- Processed Shakespeare's *Hamlet* using tokenization, n-gram generation, and sequence padding.
- Developed a multi-layer LSTM with a **4,818-word vocabulary** and 100-dimensional embeddings.
- Deployed real-time next-word prediction using Streamlit with EarlyStopping and persisted model artifacts.
